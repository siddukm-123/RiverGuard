How this works

1. Detection — YOLOv8 scans the image, or sampled frames of the video, for trucks and people (excavator/JCB detection requires a custom-trained model — see README).

2. Tracking — for video, each object gets a persistent ID across frames so dwell time and movement can be measured.

3. Clustering — nearby detections are grouped into one incident (a truck + person together is a stronger signal than either alone).

4. Zone check — if you provide a river/location, the system checks whether activity falls inside the legal buffer zone.

5. Reasoning — a transparent rule-based scorer weighs all of this and explains every point it awards. A detection is a signal to investigate, not proof of illegal mining.
